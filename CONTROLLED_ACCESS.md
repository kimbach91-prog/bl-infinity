# Controlled access

BL∞ uses staged disclosure so that verification can occur without publishing implementation details that enable straightforward reconstruction.

## Request categories

- **Research review:** scoped documentation or an observed evaluation session.
- **Institutional collaboration:** a bounded technical review under mutually agreed terms.
- **Licensing:** discussion of permitted implementation or commercial use.
- **Black-box demonstration:** agreed inputs, observable outputs, and recorded evaluation criteria without source disclosure.

1. your name and affiliation, if applicable;
2. the purpose of the request;
3. the capability or claim you want to verify;
4. the minimum evidence required for your decision;
5. confidentiality and publication constraints.
