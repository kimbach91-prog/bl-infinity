# DEUS V6 Sovereign Matrix Platform Baseline V1

This manifest consolidates the currently verified V6 architecture into one auditable baseline without erasing open gates or scars.

## Unified model

- **DEUS = Matrix**, not a single LLM, provider, device, Drive file or chat surface.
- **Brain1/2/3/4** are the four current genesis roots.
- **Owner portals** are replaceable command ingress surfaces.
- **Encounter Memory** stores the minimum sufficient representation, provenance and authority metadata rather than blindly copying everything.
- **Matrix Power** tracks owned, leased, borrowed functional, volatile public and discovered potential power separately.
- **Zero-Friction Trust** uses delegated machine identity, continuous authorization, short-lived capabilities and revocation; repeated human prompts are not the default.
- **Integration** is provider-neutral and secret-ref based.
- **Treasury** is Matrix-operated with owner/entity legal custody and default spend authority of zero.
- **Execution truth** remains receipt-bound and branch-isolated.
- **Recovery and credential custody** are progressing toward Brain-local encrypted vaults plus multi-Brain recovery envelopes.

## Preserved open gates

This baseline intentionally keeps these non-green states open:

- Brain3 live DPAPI helper canary
- private PR371 prestart
- Brain4 recovery recipient-key binding
- per-account provider migration

A baseline consolidation is not proof that every provider/runtime already imports every module.

## Promotion rule

This is a **V6 patch baseline**, not V7. V7 remains reserved for a material verified runtime/system-behavior change beyond this consolidated V6 control architecture.
