# BL∞ — Public Verification Surface

BL∞ is an independent research program by **Lâm Kim Bách (Bách Lâm / Optimizer)** on open-ended epistemology, provenance, adversarial review, and human–AI discovery systems.

This repository is intentionally a **public verification surface**, not a runtime distribution. It publishes only what is needed to identify the work, evaluate its stated scope, and request a controlled review.

## What is public

- authorship and canonical identity;
- a concise capability contract;
- disclosure and security policies;
- a stable contact path for qualified review.

Implementation topology, orchestration logic, operator sequences, private evaluation material, experimental kernels, and dependency graphs are not published here.

## Integrity

The public surface is enforced by a fail-closed allowlist in CI. Absence from this repository is intentional and must not be interpreted as a claim that an unpublished mechanism exists or has been independently validated.
