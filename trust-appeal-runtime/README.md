# DEUS V6 Trust & Appeal Case Runtime V1

Large platforms need a correction path for consequential decisions.

This generic runtime implements:
- tenant-isolated cases;
- abuse/dispute/appeal/policy/billing/data/access categories;
- evidence references instead of copying secrets;
- separation of duties between opener and reviewer;
- decision records with policy/evidence lineage;
- appeal cases linked to prior decisions;
- append-only supersession instead of rewriting history;
- SLA/overdue visibility;
- audit export with digest.

This is not a legal adjudication system and does not by itself suspend accounts, refund money, or enforce provider decisions. Production actions remain separately authorized and receipt-bound.
