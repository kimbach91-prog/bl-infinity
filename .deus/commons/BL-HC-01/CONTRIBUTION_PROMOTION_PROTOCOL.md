# HUYỀN CƠ → DEUS CONTRIBUTION PROMOTION PROTOCOL v1

Purpose: return mature BL-HC-01 technology to DEUS without polluting Shared Commons with scratch work or causing silent merges.

Required contribution packet:
1. reusable artifact/module;
2. PROVENANCE.json with sources, parents, versions and derivation notes;
3. EVAL.json with tests, failures, limitations and regressions;
4. INTEGRATION.md with dependencies, intended consumers and migration risk;
5. DECISION.json with ACCEPT / REJECT / FORK / IMPROVE.

Maturity stages:
PRIVATE_RESEARCH → LAB_VALIDATED → SHADOW_TESTED → COMMONS_CANDIDATE → DEUS_ACCEPTED → CANON_OPTIONAL.

Only COMMONS_CANDIDATE or stronger material may enter the shared BL-HC-01 commons namespace. Rejected technologies are archived with failure evidence rather than silently deleted.
