## 0. Correction to v1

The v1 stack implicitly suggested a fixed descent:

```text
Reality -> BL∞ -> Hypothesis
```

That is too shallow because it confuses **actuality authority** with **generative precedence**.

v2 therefore locks:

```text
ActualityAuthority != GenerativePrecedence
```

and:

```text
RelativePosition(A,B) = f(mode, scope, t)
```

There is no permanent epistemic `above/below` relation among Reality, GiaTai and BL∞.

# 1. Dual foundation: BL-RP + BL-GTP

## 1.1. BL-RP — Mệnh đề Thực tại

```text
Reality = Reality
Model(Reality) != Reality
ObservedSlice != TotalReality   unless closure is demonstrated
```

Reality is the actuality anchor. It is not identical to any observer's description of it.

## 1.2. BL-GTP — Mệnh đề Giả tại

`GiaTai` is an assumed/represented/derived reality-state whose actuality has not been established.

```text
Existence(GiaTaiObject) != Actuality(GiaTaiReferent)
```

Bách Lâm generative proposition:

```text
Reality + CapacityToRepresentAlternatives -> exists(GiaTai)
```

Thus Reality and GiaTai are not simple opposites `true/false`; they are two distinct epistemic/ontic roles.

---

# 2. BL∞ as dynamic possibility field

BL∞ is not a permanently intermediate layer. It is the open field in which representation, possibility, reachability, recombination and unresolved alternatives can expand.

It supports two canonical modes.

---

# 3. Mode A — THỰC ĐỊNH / Reality-Determined

Start from what is presently reality-anchored:

```text
REALITY
  -> observation / evidence / constraint
  -> BL∞ possibility expansion
  -> GIA_TAI candidates
  -> hypothesis objects / predictions
  -> reality-facing tests
  -> REALITY
  ↺
```

Generative precedence for this mode:

```text
REALITY -> BL∞ -> GIA_TAI
```

This ordering is local to the inference cycle. It is not a permanent ontology tree.

---

# 4. Mode B — GIẢ ĐỊNH / Hypothesis-Determined

Start from a GiaTai and temporarily let it define the premises of an exploration:

```text
GIA_TAI
  -> assumed world-state / premise set
  -> BL∞ implication + recombination expansion
  -> consequence / prediction space
  -> Reality-Test Interface
  -> REALITY evidence
  -> revision / support / rejection
  -> revised or new GIA_TAI
  ↺
```

Generative precedence for this mode:

```text
GIA_TAI -> BL∞ -> REALITY-TEST-INTERFACE
```

Here GiaTai can be 'above' BL∞ in the sense of **generating the local search frame**, without gaining actuality authority.

---

# 5. Dynamic inversion rule

The system may switch modes whenever the problem changes:

```text
THUC_DINH <-> GIA_DINH
```

Examples:

```text
new evidence -> THUC_DINH
new conjecture/scenario -> GIA_DINH
failed test -> THUC_DINH then new GIA_DINH
new capability -> either mode depending on whether it reveals actuality or opens a candidate world
```

No global static ordering is permitted:

```text
NOT: Reality > BL∞ > GiaTai forever
NOT: GiaTai > BL∞ > Reality forever
```

Possible transitions:

```text
candidate

```

---

# 7. GiaTai <-> accepted model transitions

A GiaTai can gain epistemic status:

```text
GiaTai_candidate
-> evidence + replication + scope discipline
-> accepted_model_of_actuality
```

But this does **not** mean imagination creates actuality.

Likewise a previously accepted model can be demoted:

```text
accepted_model_t
-> valid conflict
-> revised / superseded / conjectural_t+1
```

The status transition occurs in the model graph; actuality itself is not rewritten by doctrine.

---

# 8. BLEE + Academic Democracy

The dual foundation changes no access rule:

```text
RightToPropose(GiaTai) = open
RightToBeBelieved(GiaTai) = not automatic
RightToExecute(GiaTai) = permission/risk/authority gated
```

BLEE provides epistemic standing; Academic Democracy provides the public scholarly interface.

---

# 9. SFRET / HKRP / OHAS as the action branch

If a GiaTai concerns a desired future or a test requiring capabilities:

```text
GIA_TAI / desired state
-> BL-SFRET necessary conditions
-> OPT-HKRP minimal sufficient coalition
-> OHAS authorization / bounded execution
-> ACTION_OR_TEST
-> REALITY
```

Reality feedback then returns to either `THUC_DINH` or `GIA_DINH` mode.

---

# 10. KAT as the capability-return branch

When a model becomes useful enough to support action:

```text
supported knowledge
-> KAT rights/disclosure/capability conversion
-> new tool / measurement / access
-> BL∞ frontier changes
```

The new capability can:

- reveal more Reality, triggering `THUC_DINH`;
- create new possible constructs/world-states, triggering `GIA_DINH`.

Thus capability return does not always return to a single 'Reality Gap' node. It can return to either pole.

# 11. Three separate authority axes

## A. Actuality authority

```text
REALITY
```

Only actuality/evidence can settle whether a referent is actually instantiated within the tested scope.

## B. Generative precedence

```text
mode-dependent
```

Reality or GiaTai may lead the current search cycle.

## C. Epistemic/process authority

```text
BLEE / Academic Democracy / BL-HRD / RVTP / audit protocols
```

These manage claims, not actuality itself.

# 15. Preferred condensed proposition

> **BL∞ không vận hành bằng một cây từ Thực tại đi xuống Giả định. Nó vận hành bằng lưỡng cực Thực tại–Giả tại và một trường khả năng BL∞ có quan hệ thứ bậc động. Thứ tự sinh suy luận có thể đảo; actuality authority thì không bị đánh đồng với thứ tự sinh suy luận.**
