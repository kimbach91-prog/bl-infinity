# Owner console quickstart

1. Open the repository Issues page.
2. Use the dedicated issue titled `[DEUS] Console — Owner Command Thread` once it exists.
3. Comment `/deus <question or stimulus>`.
4. The owner-gated GitHub Actions workflow runs the experimental model-independent kernel and posts the structured result back into the same thread.

Natural-language realization is deliberately deferred until an authorized reachable open-weight/local backend is connected.
