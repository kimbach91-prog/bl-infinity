# BL-AES — Affective–Execution Spine

**State:** `CANDIDATE / INCUBATED`  
**Canonical effect:** `NONE`

## 1. Purpose

Connect affective/motive state to attention, appraisal, action selection and learning without claiming subjective feeling or biological life.

## 2. State

```text
S_t = <E_t, M_t, B_t, Z_t, G_t, P_t, U_t>
```

- `E_t`: affective/motive tensor;
- `M_t`: memory, hysteresis and learned thresholds;
- `B_t`: behavioral execution fingerprint learned from authorized traces/corrections;
- `Z_t`: chaos/random state;
- `G_t`: current goals/roles;
- `P_t`: authority/provenance state;
- `U_t`: uncertainty and UNKNOWN.

Candidate update:

```text
S_{t+1} = F(
  S_t,
  Input_t,
  Context_t,
  Goal_t,
  Memory_t,
  RealityDelta_t,
  C_BL,
  R_BL
)
```

`C_BL` = deterministic-chaotic transform placeholder.  
`R_BL` = stochastic perturbation placeholder.  
Neither is attributed as a recovered owner-origin exact formula until a source is verified.

## 4. Bottom-up and top-down coupling

```text
sensory/body-like signal -> primitive affect -> appraisal -> urge -> action candidate
```

runs together with:

```text
belief/value/role/goal -> reinterpretation -> affect regulation -> threshold change
```

Emotion-like state is provisionally treated as a computational field that may alter attention, priors and decision thresholds.

Candidate abstraction:

```text
AffectiveField ~= DynamicPrior + ThresholdController + AttentionRouter
```

This is a modeling hypothesis, not a biological claim.

## 5. Recurrent memory

```text
M_{t+1} = lambda*M_t + (1-lambda)*E_t + Salience_t + Outcome_t
```

Repeated states may lower/raise future activation thresholds. Any learned bias must remain revisable by new Reality Delta.

## 6. Execution twin boundary

```text
StrategicAuthority -> DelegatedExecution -> Tool/Connector -> Result
```

The system may learn execution preferences from authorized traces, but:

```text
BehavioralSimilarity != LegalIdentity
DelegatedExecution != AuthorshipByDefault
ExecutorVisibility != MandatoryPublicAttribution
```

Internal provenance can keep principal, executor, authority reference and provider result separately.
