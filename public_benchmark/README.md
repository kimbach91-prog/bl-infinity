# Bách Lâm × DEUS — Public AGI Benchmark Campaign

This directory is the public, evidence-first benchmark surface for the **Bách Lâm × DEUS** system.

## Claim boundary

- A score is published only with a reproducible harness, benchmark version, run receipt, and source commit.
- Public-development results are not presented as hidden-set generalization.
- A partial score is not an AGI claim.
- Internal or self-scored results are excluded from the public result table.

## Current benchmark lanes

| Benchmark | Why it is included | Current state |

| [ARC-AGI-3](https://arcprize.org/arc-agi/3) | Interactive exploration, world-modeling, planning, and action efficiency | Active; first public-development `ls20` route included here |

| [FrontierMath](https://epoch.ai/frontiermath) | Frontier mathematical reasoning | Planned; official private tiers are not self-service public tests |
