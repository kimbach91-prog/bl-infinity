For demand

  • One demand contract instead of manually comparing every route.
  • Hard budget ceiling and stop condition before execution.
  • Internal / zero-model / already-verified routes first when they satisfy acceptance.
  • External routes ranked by task fit, quality, reliability, latency, cost, privacy and reversibility.
  • Quote is a proposal, not a charge or allocation.

For providers

  • No exclusivity.
  • Start with one tiny S0/S1 canary.
  • You state capacity, availability, price/reward model and exit condition.
  • Verified work earns an attributable receipt and scoped performance evidence.
  • Eligible no-cash lanes can use public-benefit or result-swap reciprocity.
  • Paid work is offered only when exact settlement authority is verified.

MACHINE BID LOGIC

Useful value beats provider count

provider_value = task_fit + quality + reliability + latency_fit + locality + reversibility + diversity_value - cost - privacy_risk - failure_risk - lock_in_risk

Hard gates override the score. Missing authority, protected data on an ordinary public route, hidden persistence, access-control bypass or missing canary evidence means HOLD.
